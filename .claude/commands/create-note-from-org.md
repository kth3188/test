# 조직 온톨로지에서 노트 생성

조직 온톨로지에서 특정 엔티티나 주제를 선택하여 개인용 마크다운 노트로 변환합니다.

## 실행 방법
1. 조직 DB (knowledge/db/organization.db)에서 대상 엔티티를 검색합니다
2. 해당 엔티티와 연결된 관계, 속성을 모두 수집합니다
3. db-to-markdown 역변환기를 사용하여 마크다운 노트를 생성합니다:
   - 엔티티 → 노트 제목 + 정의 섹션
   - 관계 → 관련 개체 섹션
   - 속성 → 속성 섹션
   - 출처 → 출처/근거 섹션
4. 생성된 노트를 knowledge/notes/에 저장합니다
5. 개인 DB에도 파싱하여 저장합니다

## 사용법
```
/create-note-from-org [엔티티명 또는 검색어]
```

## 옵션
- 관련 엔티티 깊이: 1단계(직접 관계)만 또는 2단계까지
- 출처 표시: 조직 DB에서 가져온 정보임을 명시
