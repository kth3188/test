# 마크다운 노트 파싱

사용자가 제공한 마크다운 노트를 파싱하여 엔티티, 관계, 속성을 추출합니다.

## 실행 방법
1. `knowledge/notes/` 디렉토리에서 대상 마크다운 파일을 읽습니다
2. YAML frontmatter에서 메타데이터(title, domain, tags, confidence)를 추출합니다
3. `## 관련 개체` 섹션에서 엔티티와 관계를 추출합니다
   - 패턴: `**[개체명]**: 설명 (관계: 유형)`
4. `## 속성` 섹션에서 key-value 속성을 추출합니다
5. 비정형 텍스트는 Claude API를 호출하여 추가 엔티티/관계를 추출합니다
6. 추출 결과를 SQLite DB에 저장합니다
7. `## 미해결 질문`이 있으면 open_questions 테이블에 저장합니다

## 사용법
```
/parse-note [파일명]
```
파일명이 없으면 가장 최근 수정된 노트를 파싱합니다.

## 출력
- 추출된 엔티티 목록
- 추출된 관계(트리플) 목록
- 저장된 속성 목록
- 새로 생성된 미해결 질문
