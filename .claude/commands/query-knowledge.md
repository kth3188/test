# 지식 DB 검색

지식 DB에서 정보를 검색하고 조회합니다.

## 실행 방법
1. 사용자의 질문/키워드를 분석합니다
2. SQLite FTS5 전문검색으로 관련 노트와 엔티티를 검색합니다
3. 관련 엔티티의 관계 그래프를 탐색하여 연결된 지식을 수집합니다
4. 결과를 사용자 친화적으로 정리하여 출력합니다

## 사용법
```
/query-knowledge [검색어 또는 질문]
```

## 검색 범위
- notes 테이블: 노트 제목, 본문 전문검색
- entities 테이블: 엔티티 이름, 설명 검색
- relations 테이블: 관련 트리플 조회
- attributes 테이블: 속성 값 검색

## 출력
- 관련 노트 목록 (제목 + 요약)
- 관련 엔티티와 그 관계 그래프
- 신뢰도 표시
