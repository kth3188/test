# 탐구 질문 제안

현재 지식 DB의 상태를 분석하여 탐구할 만한 질문을 제안합니다.
"실체적 진실 추구" 철학에 따라 능동적으로 지식의 빈틈을 찾습니다.

## 실행 방법
1. 최근 작성/수정된 노트를 분석합니다
2. 기존 open_questions 테이블의 미해결 질문을 확인합니다
3. Claude API를 호출하여 다음을 분석합니다:
   - 현재 지식에서 빠진 부분 (knowledge gap)
   - 엔티티 간 누락된 관계
   - 신뢰도가 낮은 정보에 대한 검증 질문
   - 모순되는 정보에 대한 확인 질문
4. 새로운 질문을 생성하여 DB에 저장합니다

## 사용법
```
/suggest-questions [도메인 또는 엔티티명]
```
인자가 없으면 전체 DB를 분석합니다.

## 질문 유형
- **확장 질문**: "X에 대해 Y 측면은 어떠한가?"
- **검증 질문**: "X가 정말 Y인지 확인 필요"
- **연결 질문**: "X와 Z 사이의 관계는?"
- **깊이 질문**: "X의 구체적인 메커니즘은?"
