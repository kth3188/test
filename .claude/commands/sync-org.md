# 조직 온톨로지 동기화

개인 지식 DB와 조직 온톨로지 DB 간의 양방향 동기화를 수행합니다.

## 실행 방법

### 내보내기 (개인 → 조직)
1. 개인 DB에서 새로 추가/변경된 엔티티와 관계를 추출합니다
2. JSON-LD 형식으로 변환합니다
3. 조직 DB (knowledge/db/organization.db)에 병합합니다
4. 충돌 시 사용자에게 확인을 요청합니다

### 가져오기 (조직 → 개인)
1. 조직 DB에서 사용자의 관심 도메인과 관련된 새 정보를 검색합니다
2. 마크다운 노트 형태로 변환합니다 (db-to-markdown 역변환)
3. 개인 DB에 삽입하고 knowledge/notes/에 마크다운 파일을 생성합니다
4. 기존 지식과의 차이점을 하이라이트합니다

## 사용법
```
/sync-org [export|import|both]
```
기본값: both (양방향)

## 충돌 해결
- 같은 엔티티가 양쪽에 다른 정보로 존재할 경우
- 타임스탬프 기반 최신 우선 + 사용자 확인
